# 诊前质检工作台

面向健康业务评测人员的 macOS 本地工作台。支持导入数据、维护 Checklist / Prompt、生成和检查逐行 TXT、在网页终端运行评测、查看质检结果、人工标注和发布独立标注页。

## 下载与使用

[下载 macOS 安装包](./consult-qc-workbench-macos-2026.11.24.zip)（进入文件页后点击 **Download raw file / 下载原始文件**）。

1. 下载 ZIP 并解压到长期保留的文件夹。
2. 安装 Python 3.10 或更新版本：[Python 官方 macOS 下载页](https://www.python.org/downloads/macos/)。
3. 双击“启动工作台.command”。首次会创建独立环境并联网安装 requests，然后自动打开 `http://127.0.0.1:8767/`。
4. 使用自己的数据和模型密钥；完整操作说明在 ZIP 中的“使用说明.md”。

无需安装 Codex。安装器会在当前使用者桌面创建“诊前checklist”，放置评测脚本；若已有同名脚本，会保留原文件并使用另一个脚本名。评测输出默认与输入 TXT 同目录保存，正式运行同名覆盖；`--check-only` 只预检、不覆盖。

## 功能

- CSV、JSONL/TXT、XLSX 导入与字段映射，每批最多 500 条。
- Prompt 版本和来源文档管理。
- TXT 结构检查、重复 ID 检查、逐字对照源数据与 Prompt。
- 网页内本机终端，实时输出、简洁进度条和 Ctrl+C。
- 运行前写入预检、逐条保存 CSV 与检查点、检查点恢复。
- 质检结果列表、对话还原、人工一致率、备注和示例标记。
- 同义问题标签归并、命中次数与占比。
- 独立标注 HTML 导出和泡泡发布。

## 使用条件

- 本安装包面向 macOS；Windows 不支持本版网页终端。
- 模型服务和额度由使用者自行提供。
- 泡泡发布需要公司网络及自己的公司登录，包内不包含登录凭据。双击“配置泡泡登录.command”可按提示配置。
- 泡泡“公开”是所有已登录泡泡用户可见，不是无需登录的互联网公开。
- 各人的人工标注保存在各自浏览器；需导出 CSV 进行汇总。
- 仓库提供可下载安装的软件包，**不是 GitHub Pages 在线运行版**。终端和文件操作在使用者自己的电脑执行。
